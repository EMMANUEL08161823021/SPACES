# SPACES

SPACES is a modern movie discovery web application built to deliver a clean, responsive, and immersive browsing experience for users who want to explore trending, popular, and highly rated movies.

The project focuses on performance, reusable UI architecture, responsive design, and seamless API integration while maintaining a visually engaging user experience.

# Installation & Setup

Clone the repository:

```bash
git clone https://github.com/your-username/spaces.git
```

Navigate into the project directory:

```bash
cd spaces
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
